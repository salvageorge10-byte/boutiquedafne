# Boutique Dafne

Sitio web profesional para Boutique Dafne, con catálogo filtrable, selección de productos y consultas por WhatsApp.

## Estructura

La versión lista para publicar se encuentra dentro de `dist/`.

- `dist/index.html`: página principal
- `dist/styles.css`: estilos y adaptación móvil
- `dist/app.js`: catálogo, menú y pedido
- `dist/assets/`: imágenes optimizadas en WebP

Desarrollado para Boutique Dafne · La Paz, B.C.S.
